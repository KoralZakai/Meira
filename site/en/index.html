How to install
  1. Tap Download for Android and open Meira.apk.
  2. If Android asks, allow installs from this source (your browser).
  3. If Play Protect warns you, tap More details → Install anyway. On Samsung, if the install is blocked: Settings → Security and privacy → Auto Blocker → off.
  4. When you connect Google Calendar, Google says the app isn't verified yet. That's because we're in beta: tap Advanced, then go to the app.
