# בדיקה במכשיר — שינויים מהיומן (19.10)

**לפני שמתחילות:** הכול כרגע בקומיטים מקומיים. כדי שזה יעבוד במכשיר צריך (1) פוש ל-master = פריסת השרת (הכפתורים והצ'אט צריכים את `/app/change/suggest` ואת הלוגיקה החדשה), (2) APK חדש (`npm run android:release`). בלי שרת מעודכן הכרטיס יראה "אין חיבור לשרת — ההצעה תחכה" — וזה תקין.

## 1. הגדרה — כמה להציק
1. פרופיל → "כמה להציק לך?" — רואים 3 כרטיסים: שעון בלבד / עדין / מעודד. "עדין" מסומן כברירת מחדל.
2. בוחרות "מעודד", יוצאות מהמסך וחוזרות — הבחירה נשארת.
3. שולחות הודעה כלשהי לצ'אט של מאירה (זה מה שמעביר את הבחירה לשרת).
4. עברית ואנגלית: מחליפות שפה — הכותרות והדוגמאות מתורגמות.

## 2. כרטיס ב-Today
הכנה: ביומן גוגל יש ראיון (או הרצאה/מבחן) מחר או מחרתיים.
1. מזיזות אותו ביומן גוגל ליום מאוחר יותר (למשל מיום שני לשלישי).
2. באפליקציה: Today ← משיכה לרענון (או חזרה לאפליקציה).
3. מופיע כרטיס: "הראיון … הוזז", תאריך ישן עם קו ← תאריך חדש עם יום בשבוע, ושורה "יש לך עוד יום להתכונן".
4. הזזה של 10 דקות ביומן → **אין** כרטיס. הזזה של שעה באותו יום → כרטיס "מאוחר ב-שעה".
5. פגישה רגילה (רופא) → כרטיס בלי הבטחה על הכנה ובלי כפתורי לימוד.
6. × סוגר, ואחרי רענון נוסף הוא לא חוזר.
7. הזזה בצ'אט ("הראיון נדחה ליום שלישי") → מאירה מציעה שעה פנויה אחת, שאלה אחת.

## 3. כפתורי ההצעה (על הכרטיס)
1. רואים: [לימוד היום/מחר HH:MM] [שעה אחרת] [לא צריך]. השעה בערב ופנויה ביומן (לא על פגישה אחרת).
2. "שעה אחרת" → שעות עגולות פנויות + "חזרה".
3. לוחצות על השעה → שורה ירוקה "הוספתי ליומן … ✓ 🔔", והמשימה מופיעה ב-Today של אותו יום. ✓ רק אם נשמרה; 🔔 רק אם נקבעה תזכורת.
4. מיד אחרי זה: "ובבוקר של האירוע — להעיר אותך ללמוד?" עם 07:00 / 08:00 / 09:00 (פחות אם הראיון מוקדם).
5. בוחרות שעה → "אעיר אותך ב-… 🔔". **לא** נוספת משימה שנייה ביומן.
6. ברמת "שעון בלבד" נקבעת תזכורת אחת; "עדין" — שתיים (חצי שעה לפני + בשעה); "מעודד" — שלוש.
7. כיבוי שרת/אינטרנט → "אין חיבור… נסי שוב" (לא "אין שעה פנויה"). יום מלא → "אין חלון פנוי".
8. אין בשום מקום שאלה "איך תגיעי?".

## 4. התראה כשהאפליקציה סגורה
1. מזיזות אירוע ביומן גוגל, **סוגרות את האפליקציה** (מוחקות מהרשימה), לא פותחות אותה.
2. מחכות עד ~15–30 דקות (משימת הרקע של אנדרואיד; לא מדויק).
3. מגיעה התראה אחת: "🎯 הראיון … הוזז" עם התאריך. לחיצה פותחת את Today והכרטיס שם.
4. אחרי שהכרטיס הוצג על המסך — לא תגיע התראה נוספת עליו.
5. בין 22:00 ל-07:30 — אין התראה; היא מגיעה אחרי 07:30.
6. אם לא נגעו בכרטיס: התראה שנייה רק אחרי 3 שעות לפחות, ולעולם לא שלישית.

## 5. אירוע שבוטל ביומן (גוגל, יומן המכשיר ו-Outlook)
1. ביומן גוגל מוחקות אירוע עתידי עם שעה (למשל ראיון עם הכנות).
2. באפליקציה: Today ← משיכה לרענון **פעמיים**, עם הפרש של כמה דקות (צריך שני סנכרונים שבהם הוא חסר — בכוונה, נגד טעויות).
3. מופיע כרטיס: "… בוטל", התאריך עם קו, "בוטל ביומן · פנוי HH:MM–HH:MM · יש N הכנות שלו".
4. "להסיר" → האירוע וההכנות נעלמים מהיום, שורה "הסרתי… ✓", ואז הצעה למלא את החלון הפנוי. "להשאיר" → לא משתנה כלום.
5. אירוע שהזזת בעצמך באפליקציה **לא** ייחשב מבוטל. ניתוק חשבון גוגל לא יוצר כרטיסי ביטול.
6. אותו כלל ביומני המכשיר וב-Outlook: שני סנכרונים רצופים בלי האירוע, ורק אם הקריאה של אותו יומן הצליחה.

## אם משהו לא עובד
- אין כרטיס אחרי הזזה: Profile → בדיקת היומן (האם גוגל מחובר), ואז רענון. אירוע שהזזת בעצמך באפליקציה לא ייצור כרטיס (בכוונה).
- הכפתורים "אין חיבור": השרת עוד לא נפרס.
- אין התראה: Android מגבילה משימות רקע (חיסכון בסוללה) — בדקי ב-Profile שהסנכרון ברקע רשום.
